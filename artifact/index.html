07A tiny model of a plastic synapse

the toy update rule

For this learning artifact, we use a simplified Hebbian-style update:

w(t+1) = retention × w(t) + η × pre(t) × post(t)

Here η controls the size of a write, retention controls decay, and pre × post represents coincident activity in this simplified model.

scope note

Scientific boundary. This equation is an educational simplification. It is not the complete BDH update rule and is not a full biological model of synaptic plasticity.

08Why put memory in synapses?

Our experiment isolates one idea: recent activity can modify a synaptic state, and that state can influence later computation. We separate three levels of evidence so nothing here is overclaimed.

level 1 our toy model A 4×4 associative matrix with a hand-written Hebbian-style update rule, built for this artifact. Every number above came from this live computation, not from BDH.
level 2 research literature Short-term synaptic plasticity as a computational memory mechanism is an active ML research area: Rodriguez, Guo & Moraitis (ICML 2022) built recurrent units whose synapses carry transient state explicitly framed around learning and forgetting; Brito & Gerstner (2024) study plasticity rules for extracting structure from correlated input.
level 3 Dragon Hatchling (BDH) Kosowski et al. (2025) state that BDH's working memory during inference relies on synaptic plasticity with Hebbian learning using spiking neurons, and report that individual synapses measurably strengthen when BDH processes specific concepts. What's actually changing in BDH is activity-driven synaptic state, not the model's trained parameters.

Evidence boundary. Our experiment isolates one mechanism relevant to the BDH design. It does not reproduce BDH's neuron dynamics, graph structure, training procedure or benchmark performance, and it is not run on any BDH checkpoint. This artifact ≠ BDH.
